# Health Cards

A [Chickadee Bandit](https://chickadeebandit.com/app-library/health-cards) app.

Allergy and emergency health information for every family member. Generate a printable card to share with parents, caregivers, or schools.

## Features

- Allergies and emergency health information per family member.
- A printable card for caregivers, schools, or relatives.
- Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-health-cards/releases/latest/download/bundle.json
```
